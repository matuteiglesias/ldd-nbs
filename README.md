

## 📘 LDD - Notebooks

Este repositorio contiene los notebooks utilizados en el curso de **Laboratorio de Datos (LDD)**.  

### 📂 **Cómo obtener los notebooks**  

Para trabajar con los notebooks en tu máquina local, clona el repositorio y accede a la carpeta `notebooks`:

```bash
git clone https://github.com/matuteiglesias/ldd-nbs.git
cd ldd-nbs/notebooks
```

Aquí encontrarás todos los notebooks organizados por temas.
